# Alberto Watch | Luxury Timepieces

A responsive, single-page luxury watch e-commerce storefront built with vanilla HTML, CSS, and JavaScript.

## Project Structure

```text
├── index.html   # Main semantic HTML structure and layout
├── style.css    # Dark-and-gold luxury theme, animations, and responsive design
├── script.js    # Product catalog, filtering/sorting, modal, and localStorage cart
└── README.md    # Project documentation
```

## Features

- **Luxury Dark & Gold Design:** Styled with `Cormorant Garamond` serif headings, `Montserrat` body text, and subtle scroll-reveal animations.
- **Sticky Navigation & Scroll Progress:** Fixed header with active section highlighting, mobile hamburger menu, and a live gold scroll-progress indicator.
- **Interactive Product Catalog:**
  - Filter watches by category (`All`, `Chronograph`, `Classic`, `Gold`, `Mechanical`).
  - Sort timepieces by featured order, price (low-to-high / high-to-low), or name (A–Z).
- **Quick-View Product Modal:** View high-resolution imagery, descriptions, and technical specifications (case size, movement, strap, water resistance).
- **Persistent Shopping Cart:** Slide-out cart drawer powered by `localStorage` with quantity controls, item removal, live subtotal calculation, and simulated checkout.
- **Contact & FAQ:** Validated contact form with user feedback messages, newsletter subscription, and an HTML `<details>` FAQ accordion.

## Getting Started

1. Place `index.html`, `style.css`, and `script.js` in the same directory.
2. Open `index.html` in any modern web browser (no build tools or server dependencies required).
